# Brand Brief — SQL Stock Screener

*Phase 1 · audited 2026-09-11 · live site https://karashchenkoustym.github.io/Updated-Stock-Screener/*

## What exists

A single-page tool with no logo file. The "brand" is:

| Element | Current value |
|---|---|
| Logo | Text glyph `◧` in `#4f9cf9` beside the title |
| Favicon | 📊 emoji as an inline SVG data URI |
| Name | "SQL Stock Screener" |
| Tagline | "Real SQL. Real market data. Running entirely in your browser." |
| Palette | GitHub-dark clone: bg `#0d1117`, panel `#151b23`, text `#e6edf3`, accent `#4f9cf9`, up `#3fb950`, down `#f85149` |
| Type | System UI stack (-apple-system / Segoe UI / Inter / Roboto) + system monospace |
| Tone | Engineering-honest: explains trade-offs plainly, no marketing hype |

## Logo analysis

There is no real mark to anchor on. The `◧` glyph renders differently across operating systems
and the emoji favicon is indistinguishable from thousands of other dashboards. The rebuild needs
its own simple mark: a monogram built from the design system (serif "S" over a ruled column),
drawn as SVG so it can be the favicon.

## Personality keywords

**Precise · candid · data-literate · calm · a little old-school**

The owner's README voice — "The trade-off, stated plainly" — is the strongest brand asset. It
reads like a good financial journalist: exact, sceptical, never breathless.

## Direction

Move from "generic dark developer dashboard" to **market broadsheet**: warm newsprint, serif
masthead, tabular mono figures, one vermilion accent, with a matching night edition. See
[`DESIGN.md`](../../DESIGN.md).
