            Real SQL, in your browser

            This page loads SQLite compiled to WebAssembly and builds a table of stocks locally. Filters and presets only write SQL for you — you can edit any query, use GROUP BY, maths and LIMIT, and see SQLite’s own error messages.

            Real prices, refreshed daily

            A GitHub Action pulls a year of daily closes from Yahoo Finance after every US market close and computes each metric from those prices. The data is a snapshot, not a live feed — at most one trading day old. It’s for exploring ideas, not investment advice.

            Built to stay up

            No backend, no database server, no API key and no CDN: the site is plain static files, including the SQLite engine and fonts. There’s nothing that can sleep, cold-start or go down.
